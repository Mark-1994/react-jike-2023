# React 即刻项目

基于 React 构建的即刻后台管理项目。

## 项目链接

- **在线预览：** [https://mark-1994.github.io/react-jike-2023/](https://mark-1994.github.io/react-jike-2023/)
- **接口服务地址：** [https://geek.itheima.net/v1_0](https://geek.itheima.net/v1_0)
- **接口文档：** 仓库目前未提供独立的接口文档地址；项目调用上述接口服务。

## 本地运行

```bash
npm install
npm start
```

启动后访问 [http://localhost:3000](http://localhost:3000)。

## 构建

```bash
npm run build
```

## 技术栈

React、React Router、Redux Toolkit、Ant Design、Axios、ECharts。
